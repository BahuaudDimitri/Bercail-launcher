# Catalogue de Bercail

Où est quoi. Une ligne par module, composant, écran, source de données et règle métier. Mis à jour dans le même commit que le code : le test `CatalogTest` (module `:architecture`) échoue si un module ou un composant public du design system manque, ou si un fichier cité n'existe plus.

Avant toute fonctionnalité : lire ce catalogue, chercher dans le code, puis n'ajouter que ce qui manque.

## Modules

| Module | Rôle | README |
|---|---|---|
| `:app` | L'application : écran d'accueil déclaré à Android, assemblage des modules | `app/README.md` |
| `:core:domain` | Règles métier et interfaces des sources de données, en Kotlin pur | `core/domain/README.md` |
| `:core:designsystem` | Design system : jetons et composants `Bc…`, seule porte vers Compose pour les écrans | `core/designsystem/README.md` |
| `:core:testing` | Faux (fakes) des sources du domaine, pour les tests et pour la version de mise au point de l'app ; jamais dans la version publiée | `core/testing/README.md` |
| `:data:settings` | Réglages enregistrés sur le téléphone (DataStore) | `data/settings/README.md` |
| `:data:apps` | Apps installées, leurs icônes, leur lancement ; liens vers le web, le Play Store et les Paramètres | `data/apps/README.md` |
| `:data:media` | Ce qui joue sur le téléphone : sessions média d'Android (Spotify, YouTube…), pochette et ses deux couleurs, commandes ; l'« accès aux notifications » qu'Android exige pour cela | `data/media/README.md` |
| `:data:messages` | Les conversations de toutes les messageries, lues dans Beeper sur le téléphone : qui, sur quel réseau, combien de non-lus ; les deux droits que Beeper donne pour cela | `data/messages/README.md` |
| `:data:agenda` | L'agenda du téléphone : rendez-vous du jour lus dans Android, ouverture dans l'app agenda | `data/agenda/README.md` |
| `:data:weather` | La météo du lieu où est le téléphone : prévisions d'Open-Meteo, position approximative, dernière prévision gardée | `data/weather/README.md` |
| `:data:update` | La mise à jour de Bercail par lui-même : dernière release lue sur GitHub, paquet téléchargé et vérifié, remis à Android | `data/update/README.md` |
| `:feature:home` | L'accueil : ses deux écrans (Accueil, Écoute), son bandeau et la feuille des gens et de la maison, assemblés avec le design system | `feature/home/README.md` |
| `:feature:search` | La recherche : toutes les apps de A à Z, résultats par famille, propositions web et Play Store | `feature/search/README.md` |
| `:feature:settings` | « Réglages de Bercail » et le choix des apps du dock | `feature/settings/README.md` |
| `:architecture` | Tests d'architecture : « seulement le design system », interdits batterie, catalogue | `architecture/README.md` |
